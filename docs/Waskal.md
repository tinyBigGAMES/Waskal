## Overview

**Waskal** is a modern programming language designed by Jarrod Davis to bring the structured clarity of **Pascal** to the web. By utilizing the **WebAssembly memory64 extension**, the compiler transforms source code into a **single, self-contained HTML file** that runs natively in any modern browser. This approach eliminates the need for complex web toolchains, installers, or servers, offering a **frictionless deployment** model across all operating systems. The language features **strong typing**, managed strings, and advanced structured data types while delegating platform tasks like graphics and audio to a **JavaScript host layer**. Ultimately, Waskal positions the browser as a universal operating system, allowing developers to create **portable, high-performance applications** through a transparent and simplified compilation pipeline.
